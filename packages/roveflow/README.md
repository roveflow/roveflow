# roveflow

Clone any app in seconds. Plug in your iPhone or Android phone, point Roveflow at an app, and its
AI maps every screen and user journey into a shareable Atlas.

```bash
npm install -g roveflow
roveflow setup
```

`roveflow setup` gets your phone ready in one step (tap **Allow** on your Mac and
your phone passcode once). Then, in Claude Code:

```
/rove   map this app — sign-up, the main action, and settings
```

The map is saved to `roveflow-out/atlas.html` — open it and share it.

Full docs: https://docs.roveflow.dev · See the CLI reference for every command.
